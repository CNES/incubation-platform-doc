Bienvenue sur la documentation de la plateforme d'incubation CD
===================================

Ceci est un guide de mise en marche dédié au porteur/développeur de
chaînes souhaitant **convertir leurs workflow en CWL** ainsi que
**benchmarker leurs chaînes de manière autonome.**

Pour commencer, regarder :doc:`onboarding`.

Pour des information sur la rédaction de CWL: :doc:`cwl_quick_start`

.. note::

   Ce projet est encore en cours de développement
